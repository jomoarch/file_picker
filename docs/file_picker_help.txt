============================================================
  file_picker 操作帮助
  （按 H / q / Esc 关闭本页，j / k 或 ↑ / ↓ 滚动）
============================================================

【导航】
  j / ↓              光标下移
  k / ↑              光标上移
  h / ← / Backspace  返回上一级目录（根目录时无操作）
  l / → / Enter      进入光标所指目录（文件则忽略）

【选择】
  Space              切换当前条目的选中状态（不可选条目静默忽略）
  c                  确认选择并退出；无选中项时提示后按任意键继续
  q / Esc / Ctrl+C   取消选择并退出

【显示】
  .                  显示/隐藏以 . 开头的隐藏文件
  H                  打开/关闭本帮助页

【界面说明】
  顶部：当前中栏目录的完整路径 + 模式 + 选中数 + 隐藏状态
  左栏：父目录内容，▶ 标记当前所在目录
  中栏：当前目录内容，反显行为光标所在位置
  右栏：光标所指目录的子目录内容
  绿色背景：已选中的条目
  目录名以 / 结尾；符号链接以 @ 结尾（可进入，不可选中）
  栏内显示 (Empty) / (Error) 表示空目录或读取失败

【模式】
  SINGLE_FILE          单选文件（同一时刻最多选中一个）
  MULTI_FILE           多选文件（默认）
  SINGLE_DIRECTORY     单选目录
  MULTI_DIRECTORY      多选目录
  allow_files / allow_directories 可进一步限制可选类型
  （导航不受模式限制，目录始终可以进入）
