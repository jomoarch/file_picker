# file_picker
一个简单的文件路径选择工具。


跨平台：
1. Linux/macOS 使用 termios + ANSI 转义序列
2. Windows 使用 Win32 控制台 API + 虚拟终端处理）

界面文案全部为英文（含模式名、状态栏、提示信息）；帮助页文本保存在独立的外部文件中（默认 `file_picker_help.txt`，内容可为任意语言，可用中文）。

| 按键说明||
| --- | --- |
| `q` / `Esc` / `Ctrl+C` | 取消选择，立即退出（`ok=false`，`paths` 为空） |
| `c` | 确认选择。若无选中项则提示 `Empty selection`，按任意其他键后继续；若有选中项则退出并返回选中路径列表 |
| `Space` | 切换当前光标条目的选中状态（不可选条目静默忽略；选中条目以绿色背景标识） |
| `h` / `Left` | 返回上一级目录（根目录时无操作） |
| `l` / `Right` / `Enter` | 进入当前光标所指目录（若为文件则静默忽略） |
| `j` / `Down` / `k` / `Up` | 光标下/上移动一行 |
| `鼠标滚轮` | 光标上/下移动（帮助页中滚动） |
| `鼠标点击中栏` | 光标定位到点击行 |
| `Backspace` | 返回上一级目录（根目录时静默忽略） |
| `.` | 显示/隐藏以点开头的隐藏文件或文件夹 |
| `u` | 刷新缓存（重新扫描当前目录及其路径上的所有目录） |
| `H` | 打开/关闭帮助页（内容来自外部帮助文件，支持 `j`/`k` 滚动） |
| 其他按键 | 忽略 |

## 选择过滤

`SelectionMode` 只区分单/多选（`SINGLE` / `MULTI`）；可选条目的类型由过滤器决定：

- `opts.filter = select_file_only` —— 只选普通文件（目录不可选）；
- `opts.filter = select_directory_only` —— 只选目录（文件不可选）；
- 符号链接（`@` 后缀）无论过滤器如何都不可选中，但指向目录的链接可以进入；
- `filter` 未设置时除符号链接外全部可选；设置后**不被过滤器允许的条目一律灰色且不可选中**；
- 自定义过滤器：`opts.filter = [](const std::filesystem::path &p) { return ...; }`。

说明：Esc/Ctrl+C 取消是规格外的实用扩展；符号链接显示为“@”后缀，
不可被选中，但指向目录的链接可以进入。
